# Развёртывание бота на VPS (Docker)

Бот работает круглосуточно на удалённом сервере и не зависит от вашего компьютера.
Всё, что нужно от вас после настройки — редкие обновления (2 команды).

## 1. Аренда VPS

Подойдёт любой российский провайдер: **Timeweb Cloud, Aeva, VDSina, Selectel**.

Минимальная конфигурация:
- **Ubuntu 24.04** (или 22.04)
- **1 vCPU, 2 ГБ RAM** (на 1 ГБ тоже заведётся, но 2 ГБ спокойнее)
- Диск 10–20 ГБ

Стоимость: примерно **200–500 ₽/мес**. Оплата российской картой.

> Совет: у Timeweb Cloud при создании можно сразу включить **Docker** — тогда шаг 3 можно пропустить.

## 2. Подключение к серверу

Провайдер пришлёт IP-адрес и пароль (root). Подключитесь с любого компьютера
по SSH. На Windows удобнее всего **Windows Terminal** (уже встроен) или PowerShell:

```
ssh root@<IP-адрес-сервера>
```

Введите пароль. Готово, вы в консоли сервера.

## 3. Установка Docker (если не включён провайдером)

```bash
curl -fsSL https://get.docker.com | sh
```

Проверка:

```bash
docker --version && docker compose version
```

## 4. Клонирование проекта

```bash
mkdir -p /opt/ozon-bot && cd /opt/ozon-bot
git clone https://github.com/IvanPas050293/Ozon.git .
```

> Если репозиторий **приватный**, клонирование потребует авторизации:
> задайте remote с токеном (см. раздел 8, тот же токен подойдёт).

## 5. Настройка токена бота

```bash
cp .env.example .env
nano .env
```

Откройте файл `.env` и вставьте токен в строку `BOT_TOKEN=`.
Токен можно взять у **@BotFather** (команда `/token`) или из вашего локального файла
`Ozon/src/main/resources/application-local.yml`.

Сохраните и выйдите из `nano`: `Ctrl+O`, `Enter`, `Ctrl+X`.

Другие переменные можно оставить как есть — они уже подходят для УСН 6%.

## 6. Запуск

```bash
docker compose up -d --build
```

Первая сборка займёт несколько минут (скачивается Maven + зависимости).
Затем бот запустится и поднимется сам при перезагрузке сервера.

Проверка логов:

```bash
docker compose logs -f ozon-bot
```

Признак успешного старта — строка вида `Started OzonBotApplication`. Выход из просмотра логов: `Ctrl+C`
(бот при этом продолжает работать).

## 7. Проверка

Отправьте вашему боту в Telegram `/start`. Если отвечает — всё работает.
Данные (настройки магазинов, налог, себестоимость) сохраняются на диске сервера
в папке `./data`.

## 8. Обновление бота после изменений кода

```bash
cd /opt/ozon-bot
git pull
docker compose up -d --build
```

> Если репозиторий приватный, при первом клоне сразу настройте remote с токеном:
>
> ```bash
> git remote set-url origin https://<токен-GitHub>@github.com/IvanPas050293/Ozon.git
> ```

## 9. Перенос текущих данных с компьютера (по желанию)

На VPS база начнётся с чистого листа. Чтобы налог и себестоимость не настраивать
заново, скопируйте локальную базу. **На своём компьютере** (в PowerShell):

```bash
scp -r "C:\Users\Ivan\Al native developer\data" root@<IP-адрес-сервера>:/opt/ozon-bot/
```

После копирования перезапустите бот:

```bash
cd /opt/ozon-bot
docker compose restart
```

## 10. Бэкап данных

Все данные бота — это папка `data/`. Резервная копия:

```bash
cd /opt/ozon-bot
tar czf backup-$(date +%F).tgz data/
```

Файл `backup-....tgz` скачайте к себе командой (в PowerShell на компьютере):

```bash
scp root@<IP-адрес-сервера>:/opt/ozon-bot/backup-*.tgz .
```

## Полезные команды

| Команда | Что делает |
|---|---|
| `docker compose up -d --build` | Собрать и запустить |
| `docker compose logs -f` | Смотреть логи |
| `docker compose restart` | Перезапустить |
| `docker compose down` | Остановить |
| `docker compose pull` + `up -d` | Обновить без пересборки (не нужно для этого проекта) |

## Замечание о безопасности (опционально)

Контейнер для простоты работает от root. Это приемлемо для личного бота на
выделенном сервере. Если захотите ужесточить — закройте доступ к VPS по паролю
(SSH-ключи), включите `fail2ban` и настройте `ALLOWED_CHAT_IDS` в `.env`,
чтобы бот отвечал только вам.
