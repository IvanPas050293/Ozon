# Команды Claude Code

Справочник по самым популярным встроенным командам (slash-командам) Claude Code.
Полный актуальный список команд выводится вводом `/` в поле ввода — в меню можно фильтровать по буквам.

> **Алиасы:** многие команды имеют краткие дубликаты — `/review` → `/code-review`, `/cost` → `/usage`, `/settings` → `/config`, `/bg` → `/background`, `/reset` и `/new` → `/clear`, `/quit` → `/exit`.

---

## 🚀 Работа с сессией

| Команда | Что делает | Когда применять |
| --- | --- | --- |
| `/help` | Показывает справку и список доступных команд. | Если вы новичок, забыли синтаксис или хотите увидеть все команды и навыки проекта. |
| `/clear [имя]` | Начинает новую беседу с чистым контекстом. Необязательное имя сохраняет предыдущий диалог для `/resume`. | Чтобы начать задачу с нуля и освободить контекст, сохранив историю для возврата. |
| `/compact [инструкции]` | Сжимает диалог в краткое резюме, освобождая контекст. Можно указать, на чём сосредоточиться. | В середине долгой сессии, когда контекст заполняется, но прерывать разговор не хотите. |
| `/resume` | Возвращает к предыдущей беседе; показывает список прошлых сессий. | Когда продолжаете работу после перерыва, новой задачи или перезапуска терминала. |
| `/status` | Мгновенно показывает статус и параметры сессии (модель, ID сессии). | Чтобы быстро проверить, какая модель активна, когда Claude занят. |
| `/export [имя_файла]` | Экспортирует переписку в текстовый файл. | Для сохранения разбора, передачи коллеге или архива решения. |
| `/version` | Показывает текущую версию Claude Code и проверяет обновления. | Перед обращением в поддержку или установкой плагинов с требованиями по версии. |
| `/exit` | Выходит из CLI. | Для завершения работы (не путать с `/clear` — история теряется). |

## 🤖 Модель и настройки

| Команда | Что делает | Когда применять |
| --- | --- | --- |
| `/model [модель]` | Переключает модель ИИ для сессии; без аргумента — интерактивный выбор. (Работает и `Shift+Tab`.) | Когда нужна модель мощнее для сложной задачи или быстрее/дешевле для простой. |
| `/config [ключ=значение]` | Открывает настройки или задаёт их напрямую (например, `/config theme=dark`). | Для смены темы, включения подсказок, editor mode и прочих опций. |
| `/effort [уровень]` | Устанавливает уровень усилий модели: `low`–`max`. | Для быстрых простых задач — `low`, для сложных — выше. |
| `/fast [on/off]` | Переключает fast mode (более быстрые ответы). | Для ускорения ответов на повторяющихся простых задачах. |
| `/usage` (`/cost`) | Показывает использование API и стоимость текущей сессии. | Для контроля расходов токенов и денег. |
| `/memory` | Редактирует файлы памяти `CLAUDE.md`, управляет автопамятью. | Чтобы добавить информацию о проекте, которую Claude должен помнить в будущих сессиях. |

## 📋 Контекст и история

| Команда | Что делает | Когда применять |
| --- | --- | --- |
| `/context [all]` | Визуализирует использование контекста цветной сеткой с советами по оптимизации. | Чтобы понять, что занимает контекст, и решить, что сжать. |
| `/autocompact [auto\|<токены>]` | Устанавливает порог автсжатия контекста (например, `500k`). | Чтобы контекст сжимался автоматически без ручного `/compact`. |
| `/rewind` | Откатывает беседу и состояние файлов к ранней контрольной точке. | Когда Claude наделал прав, которые нужно отменить. |
| `/add-dir <путь>` | Добавляет рабочую директорию для доступа к файлам в текущей сессии. | Когда нужно дать Claude доступ к файлам вне текущей рабочей папки. |
| `/cd <путь>` | Перемещает сессию в новую рабочую директорию с сохранением кэша промпта. | Когда задача перешла в другой каталог. |

## 🛠 Планирование и выполнение

| Команда | Что делает | Когда применять |
| --- | --- | --- |
| `/plan` | Включает режим плана: Claude только читает файлы и не меняет код до вашего одобрения. | Перед крупными изменениями, когда нужно согласовать подход, не трогая код. |
| `/subtask` | Передаёт текущую задачу субагенту и ждёт результат в этом разговоре. | Для изоляции тяжёлой подзадачи (поиск, исследование) с чистым контекстом. |
| `/tasks` | Мгновенно показывает фоновые задачи и субагентов сессии. | Чтобы проверить, что делает фоновый процесс, не прерывая ответ. |
| `/background [промпт]` | Открепляет сессию как фонового агента, освобождая терминал. | Для долгих задач, которые должны идти без терминала. |
| `/fork [промпт]` | Копирует беседу в новую фоновую сессию, не останавливая текущую. | Когда нужно протестировать альтернативный вариант решения. |
| `/branch [имя]` | Разветвляет беседу в этой точке; исходник сохраняется для `/resume`. | Для «а что если сделать иначе» без потери текущей ветки. |
| `/goal [условие\|clear]` | Ставит цель: Claude продолжает работу между ходами, пока условие не выполнено. | Для автономного выполнения многошаговых задач. |
| `/btw [вопрос]` | Задаёт быстрый побочный вопрос без добавления в историю переписки. | Когда нужен короткий ответ, не раздувая контекст и не сбивая Claude с задачи. |

## 🔍 Рецензирование и безопасность

| Команда | Что делает | Когда применять |
| --- | --- | --- |
| `/code-review [уровень] [--fix]` | Проверяет текущий диф (или PR/ветку) на ошибки корректности и возможности упрощения. `--fix` применяет правки. | Перед коммитом или после открытия PR. |
| `/security-review` | Проверяет текущий диф на уязвимости безопасности. | Перед слиянием изменений, затрагивающих ввод данных, авторизацию, зависимости или сеть. |
| `/diff` | Интерактивный просмотр незакоммиченных изменений. | Для быстрого обзора того, что уже изменено. |
| `/pr-comments` | Загружает комментарии к текущему GitHub-пул-реквесту в контекст. | Когда пришли замечания ревьюеров по открытому PR. |

## 🩺 Диагностика и установка

| Команда | Что делает | Когда применять |
| --- | --- | --- |
| `/doctor` | Проверяет здоровье установки: PATH, неиспользуемые навыки/MCP/плагины, медленные хуки, размер `CLAUDE.md`. | Периодически или при подозрении, что окружение сломано или захламлено. |
| `/debug [описание]` | Включает отладочное логирование и разбирает лог. | Для диагностики сбоев и странного поведения Claude Code. |
| `/upgrade` | Обновляет Claude Code до последней версии. | Когда `/doctor` или `/version` сообщают о новой версии. |
| `/install-github-app` | Устанавливает Claude GitHub App для репозитория. | Чтобы включить автофикс PR, автоматические ревью и интеграцию с GitHub. |
| `/login` / `/logout` | Вход/выход из аккаунта Anthropic. | При переключении между аккаунтами или после ошибок авторизации. |

## 🔌 Инфраструктура и интеграции

| Команда | Что делает | Когда применять |
| --- | --- | --- |
| `/agents` | Напоминает попросить Claude управлять субагентами (файлы `.claude/agents/`). | Когда нужно создать или изменить субагента. |
| `/hooks` | Показывает конфигурацию хуков для событий инструментов. | Чтобы убедиться, что pre/post-хуки (форматирование, линтер) подключены корректно. |
| `/permissions` | Просматривает и редактирует правила разрешений сессии (allow/deny). | Когда часто спрашивают разрешение и хочется добавить исключение. |
| `/mcp [reconnect\|enable\|disable]` | Управляет подключениями MCP-серверов и OAuth. | Для подключения/отключения серверов или переподключения упавшего соединения. |
| `/vim` | Переключает Vim-клавиши в интерактивном терминале. | Если привыкли к Vim-редактированию ввода. |
| `/terminal-setup` | Инструкция по настройке терминала (починка `Ctrl+C`, привязки клавиш). | Если не работают сочетания клавиш в вашем терминале. |
| `/ide` | Управление интеграциями с IDE и их статусом (VS Code, JetBrains и т.д.). | При работе с редактором кода. |

## 💬 Прочее полезное

| Команда | Что делает | Когда применять |
| --- | --- | --- |
| `/recap` | Генерирует резюме сессии по требованию. | Когда вернулись к терминалу и нужен сжатый обзор проделанного. |
| `/insights` | Формирует отчёт по анализу ваших сессий (области проекта, паттерны, болевые точки). | Для периодической рефлексии по эффективности работы. |
| `/import [codex\|gemini]` | Импортирует конфигурацию из OpenAI Codex или Google Gemini CLI. | При миграции с других агентов. |
| `/keybindings` | Открывает файл клавиатурных сокращений для кастомизации. | Чтобы переназначить горячие клавиши. |
| `/bug [отчёт]` | Сообщает об ошибке или отправляет обратную связь. | При баге Claude Code. |

## Горячие клавиши (шпаргалка)

| Сочетание | Действие |
| --- | --- |
| `/` | Открыть меню команд |
| `Shift+Tab` | Переключить модель |
| `Esc` / `Ctrl+C` | Прервать ответ / отменить |
| `Ctrl+R` | Открыть `/resume` |
| `Double Esc` (на пустом вводе) | Меню отката (rewind) |
| `Shift+Enter` | Новая строка без отправки |
